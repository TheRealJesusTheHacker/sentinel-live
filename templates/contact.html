What to include in your message

Three things make a first message easy to act on. None of them needs to be long, and none of them needs to be technical:

What you need protected

The business, the building, the systems, the records — in your own words. “Everything, probably” is an honest answer and a fine place to start.

Where it is

A business or a home, and where in the Kansas City metro it sits. Sentinel is on-site first, so the where matters as much as the what.

Anything already going wrong. A locked account, a camera that stopped recording, a machine behaving like it is not yours — say so plainly. If it is happening right now, do not wait on this form: use the report page in the emergencies note below instead.

Emergencies

Something wrong right now?

This form is not the emergency channel. If an account is compromised, a machine is behaving like it is not yours, or data is somewhere it should not be, go straight to the report page — it is open around the clock and reaches Sentinel directly — and see incident response for how that work runs.
