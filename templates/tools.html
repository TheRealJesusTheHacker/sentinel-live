Tool one

Passphrase generator

A passphrase is a handful of ordinary words in a row — long, easy to type, and hard to guess because the combination is random. Five random words from this page's 1,300-word list carry about 52 bits of guessing resistance; six carry about 62. Add a digit and a symbol and it clears most sign-up rules too.

Tool two

Password strength checker

Type a password — or better, a password you are thinking about — and see the honest math. The estimate below counts the password's length and the size of the character set it draws from, and turns that into the number of guesses an attacker working offline would need on average. It deliberately does not punish or reward patterns, dictionary words, or clever substitutions — a real attacker's dictionary knows “P@ssw0rd!” already, so treat any result here as the best case, and length as the part that actually protects you.

The rules that actually hold up: make it long (a passphrase), make it unique to that one account, keep the set in a password manager, and turn on the second factor wherever one is offered. Complexity theater — swapping a for @ — adds almost nothing.

Why this works

The method, stated plainly

Length beats cleverness

Every extra character multiplies the guesses an attacker needs. A 20-character passphrase of plain words outlasts an 8-character knot of symbols by an enormous margin — and you can actually remember it.

Unique beats everything

The most common way accounts fall is a password stolen from one breach being tried everywhere else. A password used in exactly one place can only ever cost you that one place.
